This repo is a template for a pip installable package.  Create and activate a virtual environment.  After cloning the repo, without changing directories, execute `python python_package_template/set_package_name.py -p <new package name>`.  Read the output of the script for further instructions.

After following the steps output by the script, you have the option of using Sphinx to build documention about the package.  If you don't want to do this, feel free to delete the `docs` directory.  Otherwise, after adding modules and code in the `src` directory, `cd` to `docs` and issue `make html`.  In a browser, open `docs/_build/html/index.html` to view the documentation.  Sphinx has been configured to create API documentation for all modules.  Use `make html` at any time to remake documentation after you've made changes to the package.
