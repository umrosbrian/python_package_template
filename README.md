This repo is a template for a pip installable package.  Create and activate a virtual environment.  After cloning the repo, without changing directories, execute `python python_package_template/set_package_name.py -p <new package name>`.  Read the output of the script for further instructions.

After following the steps output by the script, you have the option of using Sphinx to build documentation about the package.  If you don't want to do this, feel free to delete the `docs` directory.  Otherwise,
assign an author in `/docs/conf.py` and make sure that the heading in `docs/index.rst` has the correct number of `=` characters below the top-level heading. After adding modules and code in the `src` directory, `cd` to `docs` and issue `make html`.  In a browser, open `docs/_build/html/index.html` to view the documentation.  Sphinx has been configured to create API documentation for all modules.  Use `make html` at any time to remake documentation after you've made changes to the package.  Note that if you've made any changes to CSS, you should use `make clean html` to discard any old CSS. 
Also, if you have see an error relating to Python code during the build (`make html`), but the code no longer exists, delete the `docs/_autosummary` directory and build again.
